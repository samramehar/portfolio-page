# Portfolio Page – FreeCodeCamp Responsive Web Design Project

This is my **Portfolio Page project** built as part of the FreeCodeCamp Responsive Web Design Certification. It showcases my basic front-end development skills using only HTML and CSS.

---

## Project Overview

This project is a personal portfolio webpage designed to display:
- My projects
- Skills
- Contact links
- Basic introduction section

It follows FreeCodeCamp’s project requirements for the **Responsive Web Design Certification**.

---

##  Built With

- HTML5
- CSS3
- Flexbox
- Basic Responsive Design Techniques

---

##  Features

- Clean and simple portfolio layout
- Responsive design (mobile-friendly)
- Navigation links to different sections
- Project showcase section
- Contact/social links section
- Modern and minimal UI

---

##  What I Learned

Through this project, I practiced:
- Structuring semantic HTML
- Styling layouts using CSS
- Using Flexbox for alignment
- Making pages responsive for different screen sizes
- Building a real-world portfolio layout
